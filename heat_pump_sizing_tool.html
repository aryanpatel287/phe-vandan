Calculation Trace (formulas)

Method note: Heating load = transmission + ventilation + infiltration − internal gains + DHW peak. Cooling load uses enthalpy-based ventilation (sensible + latent), solar gain through glazing, people gains, and internal gains. Envelope areas are derived from built-up area, floor count (square footprint assumption), and glazing ratio. All figures are peak design values at the selected climate's design temperatures. This tool supports early-stage sizing — final design must be validated with detailed load software (HAP/Carrier, Trace 700) and local code compliance.
